# BILIBILI-UP-
B站的特别关注和普通关注在提示方式和推送频率上存在显著差异。特别关注能够让你更及时地获取到关注UP主的最新动态，而普通关注则相对较为普通和常规。因此开发了此应用。这个应用可以获取自己账号下的所有关注的UP、收藏夹产出的视频内容。并且生成Obsidian的文件格式。
